# C Practical Files 🧪

A collection of C programming lab assignments and practical exercises created in **Turbo C++** for the college Computer Programming Lab coursework.

---

## 💻 Environment & Tools

* **IDE / Compiler:** Turbo C++ (DOSBox environment) / Borland C++
* **Language:** C (Standard C / C89 compliance)
* **File Format:** DOS 8.3 naming convention (`.C` files)

---

## 📂 Repository Contents

This repository serves as a digital archive for all computer lab practical files, covering:

* **Basic I/O & Operators:** Standard console input/output, arithmetic operations, and data types.
* **Control Structures:** Decision-making (`if`, `if-else`, `switch-case`) and iterative loops (`for`, `while`, `do-while`).
* **Functions & Recursion:** User-defined functions, call-by-value/reference, and recursive logic.
* **Arrays & Strings:** 1D & 2D arrays, matrix operations, and character array handling.
* **Pointers & Memory:** Address manipulation, pointer arithmetic, and basic memory concepts.

---

## ⚙️ How to Run

1. Open **Turbo C++**.
2. Mount or locate the directory containing the source files (e.g., `C:\TURBOC3\BIN`).
3. Open any required program file (`.C`).
4. Press **`Ctrl + F9`** to compile and run.
5. Press **`Alt + F5`** (or view User Screen) to inspect the program output.
